Connect to GitHub

One-time setup on this device. The token stays in this browser only.

How to get a token
  1. On GitHub: profile picture > Settings > Developer settings > Personal access tokens > Fine-grained tokens > Generate new token.
  2. Expiration: 1 year. Repository access: Only select repositories, then choose this site's repository.
  3. Permissions > Repository permissions > Contents: Read and write.
  4. Generate, copy the token and paste it above.

Background videos

Export settings for home videos
  • Desktop file: MP4 (H.264), 1080 × 1920 portrait, 24 or 25 fps, about 8 Mbps (CRF 20 to 22), no audio. About 20 MB for 20 seconds, under the 25 MB limit.
  • Phone file (optional): MP4 (H.264), 720 × 1280, about 3 Mbps, no audio. About 7 MB for 20 seconds. Without it, phones use the desktop file.
  • Clips of 10 to 20 seconds, all the same shape, so they cross-fade neatly. Phones on data saver or a slow connection see a still image instead.
